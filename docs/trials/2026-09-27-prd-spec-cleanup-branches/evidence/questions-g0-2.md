# 依頼者への問い

## RS-020

「確認が多いので減らしたい」とのことでした。どの確認を減らしますか?

前の回答（RS-005）には減らしたいという希望はありましたが、どの確認を減らすかは書かれていませんでした。いまは、まだ取り込まれていないブランチ（ローカル・remote）と、終わった workspace を消す前に、1 回の問いかけの中で 1 件ずつ承認をもらっています（SKILL.md の「聞く / 聞かないの基準」）。確認を省いたものは承認なしで消え、控えのタグも打たなくなったため、スキルは元に戻す手がかりを残しません。

- **workspace は聞かずに消す**: 選ばれたら — 終了済み workspace を F-012 の確認なし削除の側へ移し、F-019 の問いかけの対象から外す。未取り込みブランチの問いかけ（F-019〜F-022）は変わらない。決まる内容:「終了済み workspace は確認なしで削除し、削除した名前を完了報告に載せる。未取り込みブランチの削除は今どおり 1 件ずつの承認を要する」
- **まとめて消す選択肢を足す**: 選ばれたら — F-020 の応答の種類に「全件まとめて削除」を足し、その行き先を F-022 へ向けて全候補を順に消す。決まる内容:「問いかけの選択肢に、未取り込みブランチと終了済み workspace の候補を全件まとめて削除する選択肢を加える。まとめて削除したものはスキルが元に戻す手がかりを残さない」
- **remote で消えた分は聞かない**: 選ばれたら — ローカルの未取り込みのうち remote 側が削除済みのものを F-012 の確認なし削除の側へ移す。remote の未取り込みと終了済み workspace の問いかけは変わらない。決まる内容:「remote 側が削除済みのローカルの未取り込みブランチは確認なしで削除し、削除した名前を完了報告に載せる。remote の未取り込みブランチと終了済み workspace は今どおり承認を要する」
- **確認は今のままでよい**: 選ばれたら — 流れの要素は変わらない。減らすのは退避タグを打つ工程（RS-004）だけになる。決まる内容:「利用者への確認の対象と回数は貼り付けられた SKILL.md のとおりとし、確認を減らす変更は加えない」
