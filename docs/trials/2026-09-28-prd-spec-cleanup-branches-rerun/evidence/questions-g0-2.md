## RS-045

主ブランチ（main など）の remote 側まで消すと、最後に新しいブランチを作る元が無くなります。remote の主ブランチは消さずに残しますか？

依頼文で探したところ: 依頼文と回答を探したが、remote の主ブランチを消すかは書かれていない。回答の「origin/main に取り込まれてる」は remote の主ブランチが残る前提で書かれている

- **remote の主ブランチは残す**: remote の主ブランチだけは消さない。手元の主ブランチ・今いるブランチ・PR 付きのブランチはこれまでどおり他と同じに分類する（選ばれたら: F-017 に remote の primary ブランチ自身かを見る入力が加わり、その case は削除（F-018）を経ずに workspace の分類（F-021）へ進む）
- **今のまま**: remote の主ブランチも消す。新しいブランチは作れず、そこで残りの工程が止まる（選ばれたら: flow は変わらない）
