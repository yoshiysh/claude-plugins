# glossary-sync

## 概要

このスキルわ、用語集に載ってる用語が文書のなかでどう使われてるかを、用語ごとに確かめるためのもので、確かめた結果は表にまとめられ利用者へと返されるのである。

## 手順

1. `docs/glossary.md` を読み、表の 1 列目を用語の並びとして取り出す。ファイルが無ければ、用語集が無いことを利用者に返して止まる。
2. 用語の並びを `terms` として `Workflow({ scriptPath: "[SKILL_DIR]/scripts/check.js", args: { terms } })` を起動する。
3. 返った結果の並びを、用語・食い違いのある文書のパス・食い違いの内容の 3 列の表にして利用者に返す。食い違いが 1 件も無ければ、「食い違いは無い」と返す。

## 書き方

利用者に返す表は、用語の並びの順のままにしておいていただき、行の並べ替えは行わないようにしてください。表の後には、確かめた用語の数を 1 行で添えるようにしてください。
