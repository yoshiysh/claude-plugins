# Review lenses

## 共通

- 目的・要求との整合
- 仕様・実装・説明の矛盾
- 入力境界、欠損、異常系
- 失敗時の挙動と回復可能性
- 変更による互換性・回帰
- テスト、検証、観測可能性
- セキュリティ・権限・秘密情報
- 根拠不足、未定義、未検証の主張

## skill

- trigger / description の発火条件
- SKILL.md と references / scripts / schemas の整合
- 役割分担と agent 契約
- 生成者以外の検証経路
- script のゲート、算術、fan-out、早期終了の有無
- Codex / Claude など実行環境ごとの fail-closed

## code

- 正常系、境界値、例外、リソース解放
- 型・状態遷移・並行性
- API 契約、互換性、データ損失
- テストの実効性と未テスト経路

## specification / prd

- 用語と対象ユーザーの定義
- 要求、制約、受入条件、成功指標
- 曖昧な表現と複数解釈
- 状態遷移、例外、依存、非機能要件
- 実装・検証が一意に決まるか

## document

- 読者、目的、構成、参照先
- 主張と根拠の対応
- 更新時の正本と重複記述
- 欠落、矛盾、誤解を招く表現
