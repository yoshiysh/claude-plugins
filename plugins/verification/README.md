# verification

要求・仕様・コードを形式手法などで機械的に検証するスキル群

## 収録スキル

| スキル | 呼び出し | 説明 |
|---|---|---|
| `formal-method` | `/verification:formal-method` | 要求・仕様・コードを形式手法などで機械的に検証するスキル群 |

## 使い方

```
/verification:formal-method <依頼内容>
```

詳細なフローは `skills/formal-method/SKILL.md` を参照してください。

## 構成

このプラグインの `skills/` 配下がスキルの実体です。
リポジトリ内の `.agents/skills/<name>` がここへの相対シンボリックリンクになっています。
