# 思考オペレータカタログ

Plan はここから「今回どの手順で契約を満たすか」を選ぶ。各オペレータは **いつ使うか / 手順 / 出力の形** を持つ。
「逆算せよ」のような号令ではなく手順として書いてあるのは、号令は初めて見る状況に当てはめられず素通りするため。

## 目次
- 事実確認
- 逆算
- 分解
- 類推
- 反証
- 対制御比較
- 盲点洗い
- 推測の較正
- 起点別の既定の組み合わせ

## 事実確認
**いつ**: 入力に主張・数字・出典が含まれるとき。全起点の最初。
**手順**: (1) 主張を「誰が・何を・どの数字で」に分ける → (2) `research:search` に各主張を渡し verified / refuted / cannot-verify を得る → (3) verified だけを `facts[]` に出典付きで入れ、残りは `unverified[]` に分けて残す。
**出力**: `facts[{statement, source, date}]`, `unverified[{statement, why}]`。

## 逆算
**いつ**: 成功例や結果の数字はあるが、設計や手順が公開されていないとき（主張検証起点の中核、成功例を持つ動機起点の初手）。
**手順**: (1) 公開された数字を列挙する（例: 6,624 action / 183 レベル）→ (2) 各数字を「成り立つために必要な制約」に変換する（≒36 action/レベルなら、レベル間で規則を持ち越していなければ出ない）→ (3) 制約を同時に満たす構造を 1 つ以上書く → (4) 構造ごとに「これが正しければ観測されるはずのこと」を書き、測定計画に渡す。
**出力**: `constraints[{number, implies}]`, `candidate_designs[{design, predicts}]`。
**落とし穴**: 数字から一意に決まらない。候補を 1 つに絞らず、反証オペレータで潰す。

## 分解
**いつ**: 問題が複数の機序を含み、一度に測ると差の帰属先が分からないとき。
**手順**: (1) 結果に影響しうる要因を列挙 → (2) 独立に変えられる単位にまとめる → (3) 各単位に「単独で測る方法」があるか確認し、無い単位は他と束ねる → (4) 測る順序を依存関係から決める。
**出力**: `units[{name, measurable_alone, depends_on}]`。

## 類推
**いつ**: 動機起点で現状が無く、どこから手を付けるか決まらないとき。
**手順**: (1) 動機を「何が・何に対して・どうなる」の形に言い換える → (2) 同じ形の既存の解（自分のリポジトリ、既存スキル、公開実装）を探す → (3) 写像表を作る（既存の X ↔ 今回の Y）→ (4) 写像が崩れる箇所を列挙し、そこを最小試作の対象にする。
**出力**: `analogies[{source, mapping, breaks_at}]`, `first_prototype_scope`。

## 反証
**いつ**: 選択肢を採用する前。必ず。
**手順**: 各案について (1) 「この案が効かないとしたら何が起きているか」を 2 つ以上書く → (2) それぞれが当てはまるか今の事実で判定できるか確認 → (3) 判定できないものは測定計画に「これを見分ける観測」として追加 → (4) 反証が成立した案は `rejected[]` に理由付きで移す。
**出力**: 各案の `counter_conditions[]`、更新された `rejected[]`。

## 対制御比較
**いつ**: Check を数字で出したいとき。
**手順**: (1) 変える要因を 1 つに絞る（複数なら分解へ戻る）→ (2) 固定するもの（モデル・入力・環境・評価者・予算）を列挙 → (3) 指標名と向き（大きいほど良いか）を決める → (4) 反復数を決める（非決定性があるなら 3 以上）→ (5) 指標が主張を直接捉えているか自問し、捉えていなければ代理指標であることを明記。
**出力**: `conditions[]`, `fixed`, `successCriteria{text, metric, higher_is_better}`, `runsPerCondition`。

## 盲点洗い
**いつ**: 採用案を決める直前。
**手順**: (1) 「この Plan が前提にしていること」を 5 つ以上列挙 → (2) 各前提について「外れていたら Plan のどこが崩れるか」を書く → (3) 崩れ方が大きく、かつ今確認できる前提は事実確認へ回す。
**出力**: `assumptions[{statement, if_wrong, checked}]`。

## 推測の較正
**いつ**: Check の最後。必ず。
**手順**: (1) 観測された事実と、そこからの推測を別の行に分ける → (2) n・非決定性・欠測・代理指標の 4 点で「言えないこと」を列挙 → (3) confidence（script が出す）に対して人間向けの一文を添える → (4) 結果に基づく次の一手を「仮説」と明示する。
**出力**: `observed[]`, `inferred[]`, `cannot_claim[]`。

## 起点別の既定の組み合わせ

| 起点 | 既定 | 追加の判断 |
|---|---|---|
| 問題起点 | 事実確認 → 分解 → 反証 → 盲点洗い → 対制御比較（測れる場合）→ 較正 | 数字が無ければ対制御比較を外し、測定は「施策前後の同一指標」にする |
| 動機起点 | 類推 → 反証 → 較正。事実確認は主張があるときだけ | 1 周目は最小試作で現状を作る。対制御は 2 周目以降 |
| 主張検証起点 | 事実確認 → 逆算 → 反証 → 対制御比較 → 較正 | 逆算の材料が無ければ検証不能を返す |
