## 収録スキル

| スキル | 呼び出し | 説明 |
|---|---|---|
| `pdca` | `/pdca:pdca` | PDCA ループ実行スキル。契約固定・思考オペレータ選択型（問題/動機/主張検証の 3 起点） |

## 使い方

```

```

詳細なフローは `skills/pdca/SKILL.md` を参照してください。

## 構成

このプラグインの `skills/` 配下がスキルの実体です。
リポジトリ内の `.agents/skills/<name>` がここへの相対シンボリックリンクになっています。
