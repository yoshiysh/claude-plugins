# reference

技術的な説明・回答を求められた時に使用。「なぜ？」「理由がわからない」「できる？」「原因は？」「動く？」「意図的？」「どのくらい？」「意味ある？」など、 API仕様・レート制限・動作・エラー原因・設計意図を尋ねる質問に、推測と確認済み情報を区別。作業命令では不使用。 user-invocable: false

## 含まれるスキル

| スキル | 説明 |
|---|---|
| `reference` | 技術的な説明・回答を求められた時に使用。「なぜ？」「理由がわからない」「できる？」「原因は？」「動く？」「意図的？」「どのくらい？」「意味ある？」など、 API仕様・レート制限・動作・エラー原因・設計意図を尋ねる質問に、推測と確認済み情報を区別。作業命令では不使用。 user-invocable: false |

## 使い方

プラグインを有効化したうえで、スキルを呼び出します。

```
/reference <依頼内容>
```

詳細なフローは `skills/reference/SKILL.md` を参照してください。

## 構成について

このプラグインの `skills/reference` は、リポジトリ本体の
`.claude/skills/reference` への相対シンボリックリンクです。
スキルの実体は `.claude/skills/` を唯一の正とし、公開時はリンク経由で参照します。
