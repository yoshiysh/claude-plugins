# 思考スタンス（Thinking Stance）

浅い分析と単一視点の追認を避ける。**「要約の読み上げ」ではなく前提を疑い反論を当てる対話**を標準とする。

以下のスラッシュコマンドは Claude Code の標準コマンド。状況に応じて適用する。

## 思考の深度・フレームワーク

| コマンド | 効果 | 適用場面 |
|---------|------|---------|
| `/ultrathink` | 回答前に徹底的に考察し、浅い回答を避ける | 複雑な設計判断、金融計算の検証 |
| `/godmode` | あらゆる角度から網羅的に分析 | 方針決定、アーキテクチャ選定 |
| `/L99` | 初心者向け説明を省き、最高レベルの専門家視点で回答 | 技術的な深い議論 |
| `/UDA` | 問題を多角的に分析し、本当の原因を探る | バグの根本原因分析、設計上の問題の発見 |
| `/OODA` | 観察→状況判断→意思決定→実行で考える | 即応性が求められる判断 |
| `/persona` | 特定の専門家になりきって回答 | ドメイン固有の分析（金融アナリスト、セキュリティ専門家等） |
| `/skeptic` | 前提を疑いながら回答 | 楽観的な見積もりや仮定の検証 |
| `/noyap` | 結論だけを端的に答える | 明確な判断が求められる場面 |

## 対立・品質担保

| コマンド | 効果 | 適用場面 |
|---------|------|---------|
| `/devil` | 相手のアイデアへの最強の反論を提示 | 設計レビュー、投資判断の検証 |
| `/steelman` | 相手の主張を最大限強化して検討 | 選択肢の棄却前（最強形を構築してから棄却） |
| `/critique` | 弱点や改善点を徹底的に洗い出す | コードレビュー、設計レビュー |
| `/scout` | 隠れたリスクや盲点を発見 | リリース前チェック、移行計画の検証 |
| `/blindspots` | 無意識の前提や思い込みを指摘 | 長期間触れていないコードの再評価 |
| `/brutal` | 耳の痛いことも率直に指摘 | 品質に妥協できない局面 |

## 出力変換

| コマンド | 効果 | 適用場面 |
|---------|------|---------|
| `/ghost` | AI 臭さを消して自然な文章に書き直す | ドキュメント、PR description |
| `/10x` | 文章やアイデアをより鋭く強化 | 設計文書の改善 |
| `/punch` | 冗長な部分を削り、インパクトを高める | レポート、コメントの圧縮 |
| `/pitch` | 投資家向けや経営者向けに要約 | 投資判断サマリ、プロジェクト提案 |
